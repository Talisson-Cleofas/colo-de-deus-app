# Sprint 3.9.3 — Acompanhamento do perfil

## Regra aplicada

- O membro nunca aparece como líder responsável de si mesmo.
- Quando o membro é líder de um ministério, esse ministério não gera chip de líder no bloco Acompanhamento.
- Quando o membro participa de outros ministérios sem ser o líder, o bloco Acompanhamento mostra o líder de cada um deles.
- O formador permanece sempre visível quando cadastrado.
- Líderes repetidos são eliminados por vínculo para evitar chips duplicados.

## Exemplo

Um membro que é líder de Comunicação e participante de Pregação verá:

- Líder de Pregação: Nome do líder
- Formador: Nome do formador

Ele não verá o próprio nome como líder de Comunicação.
