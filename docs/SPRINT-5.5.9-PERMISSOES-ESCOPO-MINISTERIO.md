# Configuração da Sprint 5.5.9

A aba **Ministérios** da planilha deve possuir a coluna `codigo`.

Códigos suportados:

- `CELULAS`
- `EVENTOS`
- `CENACULO`
- `FINANCAS`
- `COMUNICACAO`

Quando `codigo` estiver vazio, a API tenta reconhecer o módulo por `tipo` ou `nome`, mas o código estável é recomendado.

Após o deploy, entre como Desenvolvedor na tela de Permissões e clique em **Restaurar padrões** uma vez para criar as novas permissões granulares e os vínculos padrão.
