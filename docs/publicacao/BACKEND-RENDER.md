# Backend no Render

- Root directory: raiz do monorepo
- Build: `npm install && npm run build -- --filter=@colo/api`
- Start: `npm run start --workspace=@colo/api`
- Porta: use `API_PORT` ou `PORT` conforme o serviço.
- Configure credenciais Firebase Admin, Google Sheets, Google Drive e origens CORS.
- Use HTTPS em produção.
